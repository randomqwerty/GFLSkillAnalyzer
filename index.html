This page loads the game's battle tables from the GFLData repository and explains each skill of a T-Doll, an enemy or a Coalition unit from the data itself: what triggers it, whom it targets, what every buff, hit and area does, and the quirks the in-game text leaves out.

  • Percentage buffs multiply. Two +20% buffs give ×1.44, not +40%. Tile bonuses add up with each other first, then multiply with skill buffs.
  • Hidden skills (marked “Hidden skill”) are part of the doll's kit but not shown in game; many skills only work through them.
  • Markers are buffs with no effect of their own; kits use them as switches and counters.
  • Flags: Likely bug data that cannot work as written or contradicts the skill's own text, Check something that looks unintended, Note a rule worth knowing.
  • Hidden effects lists what a kit does that none of its texts states, such as knock-back chances or buffs from hidden skills.
  • Show on the battlefield draws where an area effect lands and which dummy links it reaches; you can move the user and the target.
  • Bug scan runs every check on every doll, enemy or Coalition unit: inconsistent skill levels, descriptions that disagree with the data, buffs with wrong values or stacking, conditions that can never (or always) hold, markers bosses cannot receive, skill-order races, broken formulas and missing records.

The first visit downloads about 75 MB of tables; later visits use the browser cache until the repository changes.
